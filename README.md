# OpenWXT5S3
OpenWX Radiosonde decoder firmware for LilyGO T5S3 ePaper 

OpenWXT5S3 is the latest member of the OpenWX-Radiosonde-Decoder Suite

Based on the previous work of the other members and including the rs1729 / TTGO decoders from OpenWXTTGO / OpenWXDeck this firmware
gives you a nice and very versatile tool for field usage in radiosonde decoding. Please keep in mind the T5S3 hardware is not IP-rated!


Final release tests have been started, coming soon ...  You want to attend beta testing? Please write a mail.
